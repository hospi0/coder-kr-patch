- 대사: ADV_MG25~40.DAT(28개) + ADV_EVMG.DAT + ADV_CNDT.DAT. 앞쪽에 **빅엔디언 절대 주소 포인터 표**(0x0024xxxx = 적재 주소) — 적재 주소·표 구조는 소비 코드로 확정 필요.
